NeuroGuide V4.5 医生使用手册
个体电场仿真、TI / tES 方案规划与报告导出
适用版本：NeuroGuide V4.5（Windows 64 位）

一、先了解本软件能完成什么

NeuroGuide 根据 T1 MRI 建立个体头部电场模型，用于查看和比较不同电极位置、电流设置及靶区选择下的仿真结果。主要功能包括：

1. 导入 NIfTI 格式的个体 T1 MRI，或从 DICOM 文件夹选择并转换 T1 序列，生成组织、电极及电场计算模型。
2. 使用内置参考 MRI 进行演示和标准头模型方案探索。
3. 在个体 MRI 上确定球形靶区，或通过 AAL3 图谱选择一个或多个脑区。
4. 自动搜索 TI 双电极对方案或 tES 多电极方案。
5. 输入已有电极方案和电流，计算并查看对应电场。
6. 同屏查看三个方向的 MRI 切片、电场分布和 2.5D 切面。
7. 查看电极示意图、靶区场强统计，导出 PDF 仿真报告。
8. 记录患者基本信息，并在生成报告时选择关联记录。

本版提供电场仿真和方案评估功能，不连接或控制刺激设备，也不输出真实刺激。计算结果需结合影像质量、模型适用性和既定诊疗／研究方案解释；电场分布本身不能直接确定疗效或实际刺激的安全性。

手册中的“默认值”仅表示软件打开时的初始设置，不是针对患者的治疗建议。实际使用的电极、电流、频率、时长及设备设置，应按本机构流程另行核定。

二、首次使用：先做一次完整演示

推荐先使用内置 MRI 熟悉操作，再导入个体影像。

完整流程：
启动软件 → 新建刺激方案 → 选择 MRI → 生成电场模型 → 选择刺激方式与靶区 → 自动规划或输入已有方案 → 核对电场和电极 → 导出仿真报告。

操作步骤：
1. 完整解压 NeuroGuide-V4.5.zip，将整个文件夹放在可写入的磁盘位置。
2. 在解压后的文件夹中双击 NeuroGuide-V4.5.exe。
3. 在首页点击“新建刺激方案”。
4. 在右侧“1 影像”中点击“使用内置 MRI”，再点击“生成电场模型”。
5. 模型完成后，在“2 靶区”中选择靶区，并确认上方“刺激方式”。
6. 点击“自动规划并查看电场”，等待方案和电场显示。
7. 使用“查看电极”和“导出仿真报告”检查并保存结果。

内置 MRI 是参考影像，不代表当前患者的个人解剖。演示报告中的患者信息应与参考影像用途区分。

三、启动与使用前准备

日常使用只需运行主程序。请保留同目录中的 NeuroGuideWorker.exe 和 _internal 文件夹，以及文件夹内的其他资源。

软件会自动检查可用计算设备。可用时使用 GPU 加速；GPU 不可用或运行条件不足时，可能改用 CPU，耗时会增加。计算期间可在界面下方查看进度，在“运行详情”中查看阶段耗时与提示。

准备个体影像时，请确认：
• 文件对应本次需要评估的患者／受试者，影像日期与身份信息已核对。
• 准备 T1 MRI：可直接选择 NIfTI 文件（.nii 或 .nii.gz），也可通过“导入 DICOM…”转换已确认的 T1 序列。
• 头部覆盖范围、方向和图像质量适合本次建模；严重伪影、明显截断或分割异常应先核查。
• DICOM 应为已解压的影像文件夹；仅修改文件后缀不能完成转换。软件在本机转换，无需上传影像或另行安装转换工具。
• 原始影像和生成结果保留足够的磁盘存储空间。

患者记录与 MRI 不会自动完成身份配对。选择影像、关联患者记录及导出报告时，均需人工核对。

四、认识主界面

首页：
“新建刺激方案”进入影像建模与方案规划；“患者记录”用于录入和查看患者基本信息。

工作区左侧：
显示三个方向的 MRI 切片，以及右下方的“2.5D 切面”。各切片上方有 X、Y、Z 滑杆和坐标／层数信息。影像上方可调整色表、透明度及定位标记。

工作区右侧：
上方选择“TI · 双电极对”或“tES · 多电极”。下方依次为“1 影像”“2 靶区”“手动方案”。“方案与结果”区域显示电极、电流和靶区场强，并提供报告和电极图入口。

工作区下方：
显示运行状态、进度和“运行详情”。计算期间可使用“取消计算”。

可以拖动影像与右侧面板之间的分隔线调整宽度。部分设置需要在右侧面板内滚动查看。

五、导入 MRI 并生成个体模型

1. 打开“1 影像”，点击“选择…”，选择本次个体的 T1 MRI 文件。
2. 核对右侧文件名，并浏览左侧影像，确认影像归属及覆盖范围。
3. 选择影像后，软件会自动检查是否已有可复用的完整模型。
4. 如提示已有模型，核对影像后选择使用；首次使用或没有可复用结果时，点击“生成电场模型”。
5. 等待组织分割、电极定位和导联场计算完成。导联场可理解为后续计算不同电极方案所使用的个体电场基础数据。
6. 看到“模型已就绪”等提示后，进入靶区选择或手动方案计算。

使用 DICOM 影像时：
1. 在“1 影像”点击“导入 DICOM…”，再点击“选择 DICOM 文件夹…”。软件会扫描该文件夹及子文件夹。
2. 列表显示患者姓名、患者编号、检查日期、序列号、序列描述／协议、模态、文件数、矩阵／帧数及图像类型。文件数不一定等于切片数，多帧 DICOM 可能在一个文件中包含多层影像。
3. 点击一个序列查看样本预览。预览仅为一个文件中的样本切片，不代表完整头部覆盖范围；预览未经解剖方向重排，不用于核对左右方向。
4. 对照原始检查资料，核对患者及检查日期，并确认所选序列为本次需要的 T1 结构像。软件不会根据名称替您判断 T1，不能将 T2、FLAIR 或定位像用于本流程。列表默认不选择任何序列。
5. 勾选“我已核对患者及检查信息，并确认所选序列为用于建模的 T1 结构像”，点击“转换并载入所选序列”。更换序列后必须重新勾选确认。非 MR 序列不能转换导入。
6. 如同一序列产生多份可用影像，软件会再次要求选择转换结果；取消选择不会替换当前 MRI。若提示部分输出不符合要求，请核对剩余影像，必要时联系影像或技术人员。
如转换工具报告警告，软件会先显示提示；默认取消载入。请核查提示后决定是否载入查看，必要时联系影像或技术人员。
7. 转换后自动载入所选影像，请在主界面浏览完整 MRI，检查患者、头部覆盖、影像内容及方向，再手动点击“生成电场模型”。导入过程不会自动开始建模。
8. 原始 DICOM 不会被修改。转换结果保存在程序文件夹下 NeuroGuide/dicom_imports/ 的独立子文件夹内；此处影像及转换日志仍应按患者资料管理。若转换失败，请根据窗口提示核查影像完整性与格式，必要时由技术人员处理后导入 NIfTI 文件。

首次建模通常比后续调整方案耗时更长。模型完成后，更换靶区、调整电流、切换 TI／tES 或比较其他电极方案，通常可共用当前个体模型。

重新选择另一张 MRI 会重新检查相应模型，并清除当前界面的旧靶区、图谱和方案状态。操作前请先导出需要保留的报告。

六、选择靶区：两种方式

靶区又称 ROI，表示本次希望评价的目标区域。自动规划必须先明确靶区。

方式 A：在 MRI 上点选／输入个体坐标

1. 进入“2 靶区”，选择“在 MRI 上点选”。
2. 在左侧切片上点击或拖动十字光标，必要时用滚轮或滑杆切换切片。
3. 点击“使用当前十字光标”，将当前位置记录为靶区中心；也可直接填写 X、Y、Z 个体坐标。
4. 确认“目标区域半径”。该方式生成以所选位置为中心的球形 ROI，软件初始半径为 10 mm。
5. 点击“定位靶区”，在三个切面中核对所选中心和范围。

坐标单位为 mm，采用当前个体 MRI 的 RAS 物理坐标：X 正方向向右、Y 正方向向前、Z 正方向向上。这里的个体坐标不能直接等同于 MNI 或其他系统中的坐标；输入框不会自动完成其他坐标系到个体 MRI 的转换。核对位置时，应结合当前影像方向信息和解剖结构。

方式 B：按 AAL3 脑区选择

1. 在靶区选择中切换为“按 AAL3 脑区选择”。
2. 点击“准备 AAL3 脑区图谱”，等待图谱映射到当前个体 MRI。
3. 在搜索框输入中文或英文脑区名称，例如“海马”或“hippocampus”。
4. 勾选所需的左侧、右侧或多个脑区；多个脑区共同构成本次 ROI。
5. 在 MRI 中核对脑区位置、侧别及覆盖范围，再开始规划。

图谱配准是单独的计算步骤，同一个体模型可以复用已准备的图谱。列表中无法勾选的脑区，可能没有被当前模型的有效计算范围覆盖。图谱分区是解剖参考，最终靶区仍需结合个体影像核对。

七、自动规划方案

1. 确认当前个体模型和靶区。
2. 在上方“刺激方式”选择 TI 或 tES。
3. 如需按既定方案限制电流、电极数量或候选位置，展开“高级设置 · 电流上限与搜索参数”并核对相应设置。
4. 点击“自动规划并查看电场”。
5. 等待计算结束，方案、电流和电场会自动显示并保存。
6. 查看靶区均值、靶区峰值和靶区之外的电场分布，再使用“查看电极”核对方案。

软件提供两种优化方向：
• “优先提高目标区域场强”：侧重提高模型中目标区域的场强表现，为初始选项。
• “优先集中在目标区域”：侧重目标与非目标区域的分布关系，结合评价阈值和非目标区域惩罚设置进行搜索。

自动规划是在当前模型、靶区和约束条件下搜索候选方案，不能据此认定已经获得全局最优方案，也不会自动完成临床方案审核。比较多次结果时，应记录并核对靶区、电流约束及优化方向是否一致。

八、TI 双电极对模式

TI 模式包含两个通道，每个通道设置一对电极，合计使用四个不同电极。界面电流单位为 mA，表示每个通道的峰值；结果中的“±”表示交流峰值含义，不是要求在输入框中填写负的幅值。

已有 TI 方案时：
1. 选择“TI · 双电极对”，打开“手动方案”。
2. 分别为“通道 1”和“通道 2”选择正极、负极，核对四个电极互不重复。
3. 为每个通道填写峰值电流。
4. 如需评价特定靶区，可在同页设置靶区；未设靶区时仍可计算全场分布，但没有相应的靶区统计。
5. 点击“计算并查看电场”。

软件初始设置为每通道峰值上限 2 mA，两个通道独立约束；当前 TI 模式没有另外设置“两通道电流之和”的上限。需要其他约束时，应在方案核定和设备设置环节另行核对。

本版 TI 界面不设置载波频率、频差、刺激时长或刺激时序，也不将这些参数发送至设备。当前显示的电场幅度及报告不能替代完整的设备刺激参数单。

九、tES 多电极模式

tES 模式为每个电极指定带符号电流。软件初始为 5 个有效电极，单电极电流绝对值上限 2 mA，全部电极电流绝对值之和上限 4 mA。

已有 tES 方案时：
1. 选择“tES · 多电极”，在高级设置中核对电极数量和电流约束。
2. 打开“手动方案”，逐行选择电极并输入带正负号的电流。
3. 核对所有电极互不重复，所选电极的电流均非零，数量与设置一致。
4. 核对“带符号合计”为 0 mA，并满足单电极与电流绝对值合计限制。
5. 如需靶区统计，可选定靶区；未设置靶区仍可计算分布。点击“计算并查看电场”。

“带符号合计”和“绝对值合计”是不同指标：前者计算正负电流相加的结果，要求平衡为 0；后者计算各电流绝对值相加的结果，用于核对总量约束。

当前 tES 模型用于直流值，或同频交流、0°／180°相位条件下的峰值幅度计算。正负号用于表达模型中的电流方向／相位关系，场强幅度优化不等同于特定的神经兴奋或抑制效应预测。

上述 TI／tES 数值均为软件初始计算设置，不是可直接执行于患者的刺激处方或安全上限。

十、怎样查看和比较结果

1. 浏览切片
在某一切片上滚动鼠标滚轮可切换该平面的层面；点击或拖动可移动定位点。也可使用各切片上方的 X、Y、Z 滑杆。当前显示保留影像扫描方向，核对左右和位置时应结合影像方向信息及坐标。

2. 查看 2.5D 切面
右下方显示三个空间切面，可调整视角，并通过拖动切面联动定位。“重置视角”恢复观察视角，保留当前切片位置、靶区和电场数据。

3. 调整显示
色表和透明度用于改善观察效果。“定位标记”控制十字光标显示；“显示靶区轮廓”显示 ROI 边界；“仅在靶区内显示电场”只改变显示范围，不会重新计算或修改方案。

4. 理解颜色与实际数值
电场单位为 V/m。TI 显示包络幅度，tES 显示相应模型的场强幅度。颜色用于显示数值高低，不直接代表疗效或安全性。
默认色标下限、上限分别为当前电场峰值的 5% 和 95%，不是体素的百分位数。超过色标上限的数值会显示为最高颜色；查看真实最大值时，应看“实际峰值”等数值，而不是只看颜色。
调整色标、透明度或显示裁剪不会改变场数据，也不会改变已计算的靶区统计。比较不同方案时，建议核对相同的靶区，并采用一致的色标数值范围。

5. 区分靶区统计与全场峰值
“目标区域均值”表示有效 ROI 内的平均场强；“目标区域峰值”表示有效 ROI 内的最大场强。“实际峰值”可能来自靶区之外，两者不能混为一谈。没有有效靶区或模型未覆盖目标位置时，应先核查 ROI。

6. 查看电极
点击“查看电极”，核对电极名称、通道配对及电流标注。图中的电极位置是模型和标准电极布局下的示意，实际贴放仍需按本机构流程和设备要求另行确认。

十一、导出 PDF 仿真报告

1. 完成电场计算，并确认当前显示的是准备导出的那一次方案。
2. 点击“导出仿真报告”。
3. 在弹窗中选择已有患者记录，或手动填写姓名、年龄、性别及患病类型。
4. 再次核对患者与 MRI 的对应关系，以及报告中的刺激方式和电流方案。
5. 点击“确认生成报告”。
6. 等待成功提示，按照提示中的实际路径打开 PDF 并核查内容。

报告默认保存至当前用户的桌面目录，文件名包含姓名／报告标识及生成时间。请以软件成功提示中的路径为准。本版不是通过“另存为”对话框选择输出位置；需要归档到其他位置时，可在生成后复制 PDF。

报告采用 A4 横版单页，包含患者信息、电极与电流方案、可用的靶区统计、三个方向的切片及模型说明。已保存 ROI 的报告切片按该 ROI 的代表位置重新生成，可能与导出前停留的浏览切片不同。

自动计算得到的电流应通过方案重新计算来修改；在报告信息弹窗中填写患者资料不会改变已完成的仿真结果。报告生成后请核对患者、影像、靶区和电极方案，再按本机构流程归档。

十二、患者记录与数据保存

在首页进入“患者记录”，点击“+ 新建患者记录”，填写相应信息后选择“保存记录”。导出报告时，可以选择该记录以填入基本信息。患病类型字段用于记录，不会据此自动指定靶点或推荐刺激方案。

模型与方案结果自动保存在程序目录下的 NeuroGuide/individualized/ 文件夹。原始 MRI、该结果文件夹及导出的 PDF，应按需要一并备份。患者记录的实际存储位置显示在“患者记录”页面底部；备份时以该位置为准。

模型和方案的自动保存不等于自动生成 PDF。需要供阅读或归档的报告时，仍应执行“导出仿真报告”。

V4.5 首次使用旧版结果时，软件可能要求重新生成模型。能否复用以程序校验结果为准。迁移软件或结果时，尽量保留原始 MRI 与任务文件的原有组织方式，勿手工改写任务数据。

患者记录、MRI 和报告可能包含身份信息，应按本机构要求管理、备份和脱敏。向技术人员提供材料时，应先确认所提供内容的范围。

十三、常见问题

1. “自动规划”暂时不能开始。
先确认个体模型已完成，再确认已经设置有效靶区。采用 AAL3 时，需要先准备图谱并勾选脑区；采用坐标方式时，需要记录十字光标或填写坐标。

2. “计算并查看电场”提示电极方案有误。
TI 请检查四个电极是否重复；tES 请检查电极数量、重复位置、零电流、带符号合计以及单电极／绝对值合计限制。

3. 计算耗时较长，或提示使用 CPU。
查看界面下方进度与“运行详情”，确认当前阶段和提示。使用 CPU 或处理较大影像时会更慢；计算期间可保持程序运行，避免重复启动同一任务。

4. 需要中止计算。
使用“取消计算”，等待状态变为已取消。再次选择同一影像并启动时，软件会检查能否复用已完成部分；是否续算由文件完整性和兼容性检查决定。

5. 看不到电场，或颜色看起来异常。
确认已经完成方案计算，检查“显示内容”中的电场图层、透明度和“仅在靶区内显示电场”设置；可点击“恢复默认范围”恢复色标。若解剖位置、左右关系或组织分布明显异常，应先核查影像和模型。

6. 脑区选不到，或提示靶区没有有效体素。
检查当前图谱是否属于当前个体模型，以及 ROI 是否处于模型覆盖范围内。核对坐标类型、脑区侧别和目标半径，再调整选择。

7. 提示缺少文件或模型资源。
确认已经完整解压，主程序、Worker 和 _internal 文件夹保持在原来的相对位置；仍有问题时，将错误提示及“运行详情”提供给技术人员核查。

8. PDF 生成失败或找不到报告。
确认已完成电场计算，查看成功／失败提示中的路径，检查桌面目录是否存在、是否有写入权限。保留错误提示，供技术人员核查。

十四、每次完成方案前的核对

□ 当前 MRI 与患者／受试者身份、日期对应。
□ 当前模型和图谱对应本次影像，解剖与方向已核查。
□ 已明确使用个体 MRI 还是内置参考 MRI。
□ 靶区、侧别、坐标来源及范围已确认。
□ TI／tES 模式、电极位置、电流单位和约束已确认。
□ 已查看靶区均值、靶区峰值以及靶区之外的电场分布。
□ PDF 中的患者信息、方案和当前计算结果对应。
□ 原始影像、任务结果和 PDF 已按需要保存与备份。

本手册说明 V4.5 的软件功能与操作流程。实际刺激所需的完整参数和执行条件，应另行核定并记录。
